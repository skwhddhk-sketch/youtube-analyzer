# Viral Radar v21

## 변경 사항
- YouTube API 실제 검색 연결 추가
- API 키는 코드에 포함하지 않음
- 저장 버튼으로 입력한 키만 localStorage에서 사용
- Demo ON: 기존 샘플 데이터 사용
- Demo OFF: 실제 YouTube Data API 검색 사용

## 테스트 순서
1. 브라우저에서 사이트 열기
2. API 키 입력 후 저장
3. Demo OFF로 전환
4. 검색 탭에서 키워드 검색
5. 결과 표가 실제 영상으로 뜨는지 확인
